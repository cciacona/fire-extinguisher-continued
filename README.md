# Fire Extinguisher Continued

An unofficial continuation of **Fire extinguisher** by Devilwarriors, updated for Factorio 2.1.

Tired of accidentally burning the only forest that buffer your factory pollution from those nasty bitter. Fear no more, the fire extinguisher is here for you.

## Features

- Extinguishes nearby flame entities and removes active vanilla fire stickers from burning buildings and units.
- Scales the gun's range and each canister's extinguishing radius with item quality.
- Uses new extinguisher sounds.
- Includes descriptions with range and radius tooltips.
- Requires sulfur processing before the extinguisher technology can be researched.

## Quality bonuses

| Quality | Gun range | Canister radius |
| --- | ---: | ---: |
| Normal | 15 tiles | 1.00 tiles |
| Uncommon | 16.5 tiles | 1.15 tiles |
| Rare | 18 tiles | 1.30 tiles |
| Epic | 19.5 tiles | 1.45 tiles |
| Legendary | 22.5 tiles | 1.75 tiles |

Quality bonuses work when the Quality feature is available. The mod also works with the base game alone.

## Compatibility

- Factorio 2.1
- Cannot be enabled at the same time as the original `extinguisher` mod because both provide the same gameplay prototypes.
